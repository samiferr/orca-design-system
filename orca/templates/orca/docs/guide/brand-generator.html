    4. Copy the settings

    Paste this into your settings.py. Keys you leave at their defaults are not written.

    Python
    ORCA = {
    "BRAND": {
        "name": "Acme",
        "color": "#0f95a1",
    },
    "THEME": "auto",                    # auto, light, dark or paper
    "DENSITY": "comfortable",           # or "dense"
    "DOCS_ENABLED": True,               # serve this documentation in your project
}
