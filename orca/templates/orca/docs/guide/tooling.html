Command line (no project needed)

python -m orca list                 # {{ stats.elements }} elements by category
python -m orca list inputs          # one category
python -m orca show button          # why, when, how, example
python -m orca search date          # by name, guide item or class
python -m orca icons                # {{ stats.icons }} icon names and the aliases
python -m orca tokens               # brand keys, semantic colours, scales
python -m orca json                 # the whole catalogue

Installed as a package, the same commands are also available as orca show button.

In a Django project

CommandWhat it does
manage.py checkValidates settings.ORCA: unknown keys, bad values, colour adjustments.
manage.py orca_lint [paths]Checks templates and CSS against ORCA's rules. Defaults to your template and static folders. Exit status 1 on problems.
manage.py orca_element [id]Prints an element, or lists every id.
manage.py orca_site <folder>Exports this documentation as static HTML, with your brand.

Publishing this documentation

The export writes one HTML file per page with relative links, plus ORCA's static files, so the folder works on any static host or straight from disk.

python demo/manage.py orca_site site/
python -m http.server --directory site 8000

The repository's GitHub Actions workflow (.github/workflows/docs.yml) runs the tests, exports the site and deploys it to GitHub Pages on every push to the main branch. Enable it once under the repository's Settings, Pages, Source: GitHub Actions.

Maintaining ORCA

python -m orca build                                   # tokens.css, docs/primitives/, catalogue.json
python -m django test tests --settings=tests.settings  # the suite
python demo/manage.py runserver                        # this site at /orca/
  • Tokens live in orca/tokens.py; elements in orca/catalogue/, one module per category.
  • The suite fails when a generated file is stale, when a guide item has no element, when an element lacks its why, when or how, when an example uses a class or token that does not exist, when contrast drops in any theme, or when a page of this site breaks.
