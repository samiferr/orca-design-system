Install the package, add the app, set your brand and load ORCA in your base template. About five minutes.

{% endblock %} {% block article %}

Requirements

  • Python 3.10 or later.
  • Django 4.2 or later, with django.contrib.staticfiles.
  • No JavaScript build step, no CSS framework, no Node. ORCA ships ready-to-serve CSS, fonts and one optional script.

1. Install the package

pip install git+https://github.com/samiferr/orca-design-system.git

Pin a version in your requirements file once releases are tagged, for example orca-design-system @ git+https://github.com/samiferr/orca-design-system.git@v0.3.0.

2. Add the app and your brand

INSTALLED_APPS = [
    # ...
    "django.contrib.staticfiles",
    "django.contrib.humanize",   # optional: naturaltime for relative times
    "orca",
]

ORCA = {
    "BRAND": {
        "name": "Acme",
        "color": "#0f95a1",
        "logo": "brand/logo.svg",       # in your STATICFILES
        "favicon": "brand/favicon.svg",
    },
    "THEME": "auto",                    # auto, light, dark or paper
    "DOCS_ENABLED": True,               # serve this documentation in your project
}

Every key is optional. Without ORCA you get the default brand. The full list of brand keys is in Brand and themes.

3. Load ORCA in your base template

{% verbatim %}{% load orca %}


  
  
  {% block title %}{% endblock %} · Acme
  {% orca_head %}
  {# your own stylesheet after ORCA, using --orca-* tokens only #}


  Skip to main content
  
{% block content %}{% endblock %}


{% endverbatim %}

{% templatetag openblock %} orca_head {% templatetag closeblock %} writes the token and primitive stylesheets, your brand values, the favicon, the theme restore and the optional script. {% templatetag openblock %} orca_html_attrs {% templatetag closeblock %} writes lang and, when you fix a theme, data-theme.

4. Optional: serve this documentation

from django.urls import include, path

urlpatterns = [
    # ...
    path("orca/", include("orca.urls")),
]

The pages render with your brand, so they double as a living style guide for your team. Turn them off in production with ORCA["DOCS_ENABLED"] = False.

5. Check the setup

python manage.py check
python manage.py orca_lint templates/

System checks report unknown ORCA keys (orca.E001, orca.E002), invalid themes (orca.E003) and brand colours ORCA had to adjust for contrast (orca.W001).

Content Security Policy

ORCA writes one small inline <style> (brand values) and, with the automatic theme, one inline <script> that restores the reader's theme before the page paints. If your request carries a csp_nonce attribute (as set by django-csp), ORCA adds it to both. To avoid the script, fix a theme or call {% templatetag openblock %} orca_head theme_restore=False {% templatetag closeblock %}.
