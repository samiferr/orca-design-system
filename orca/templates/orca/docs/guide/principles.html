Every element names the rules it follows. This page turns that around: each rule, with the elements that follow it. It is built from the catalogue, so it is always complete.

Sources

  • Laws of UX, Jon Yablonski, 2nd edition, 2024: ten observations about how people perceive and decide.
  • Practical UI, Adham Dannaway, 2nd edition, 2024: concrete rules for colour, layout, type, writing, buttons and forms. ORCA uses the rule codes from its study guide (F01, C03, R14…).
  • The ORCA Design System Guide: the inventory and the five levels, after Brad Frost's Atomic Design.

These are guidelines, not laws. When two of them pull in different directions, the element's “How to use” says which one ORCA chose.
