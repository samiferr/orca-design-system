Translation

Primitives contain no fixed words. Labels, button text and messages are yours, so translate them with Django as usual. Set the page language with {% templatetag openblock %} orca_html_attrs LANGUAGE_CODE {% templatetag closeblock %}.

Django template
{% verbatim %}{% load i18n orca %}
{% get_current_language as LANGUAGE_CODE %}

...
{% endverbatim %}

Write the source text the ORCA way (sentence case, a verb on every button, errors that say how to fix) and ask translators to keep that style.

Text expansion

Translations are often much longer than English. Buttons widen, titles wrap, and tags and badges shorten with an ellipsis. Only controls where width carries meaning, such as digit boxes and weekday toggles, stay fixed. Test with your longest language before you release.

Right-to-left

Primitives use logical properties (inset-inline-start, padding-inline), and marks that point a direction flip under dir="rtl": separator chevrons, accordion chevrons and the select arrow. For right-to-left languages, set dir on <html>.

Dates, times and numbers

  • Turn on USE_TZ, store times in UTC and convert to the viewer's zone with {% templatetag openblock %} timezone {% templatetag closeblock %}; store zones as IANA names (see the timezone select).
  • Format with Django's date and time filters and the locale's DATE_FORMAT and TIME_FORMAT; write months in words for mixed audiences (date label).
  • Native date and time inputs follow the reader's locale on their own, including 12 or 24 hours.
  • Start weeks on the locale's first day (FIRST_DAY_OF_WEEK) in weekday toggles and calendars.
  • Group digits with intcomma or USE_THOUSAND_SEPARATOR; ORCA sets tabular figures so columns align in every script that has them.
