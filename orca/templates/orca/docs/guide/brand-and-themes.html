How ORCA treats your values

  • Accepted liberally. "0F95A1", "#06c" and "rgb(15, 149, 161)" all work and are normalised to lowercase hex.
  • Adjusted for readability. Brand fills that carry text are darkened (or lightened) until --orca-brand-on reads at 4.5:1. The accent is darkened to 4.5:1 on the light and paper grounds; its dark-theme value is derived and lightened to 4.5:1 on the dark grounds.
  • Reported. Every adjustment appears as the system-check warning orca.W001 with the value used, so you can set it explicitly and silence it.
  • Strict about the rest. Unknown keys and unreadable values are errors (orca.E002), and orca_lint flags any stylesheet that redefines a non-brand --orca-* token.

Examples

# A purple brand with white text: ORCA darkens the fill if needed
ORCA = {"BRAND": {"color": "#7a1fa2", "on_color": "#ffffff"}}

# A pale accent: ORCA darkens it for light themes and derives the dark one
ORCA = {"BRAND": {"accent": "#7fb2ff"}}

# Your own typeface (load it yourself, e.g. in your base template)
ORCA = {"BRAND": {"font_sans": '"Inter", system-ui, sans-serif'}}

  • ORCA["THEME"] = "auto" (default): follows the operating system, and a data-orca-theme-toggle button lets each reader choose; the choice is remembered in their browser.
  • "light", "dark" or "paper": one theme for everyone, written on <html> by orca_html_attrs.
  • Set the theme on <html> only. The previews above are a documentation-only exception that scopes the theme tokens to a box.

Density

Density is separate from the theme: any theme can be comfortable or dense. Dense tightens the type scale (body 14px, detail 13px), control heights (32px instead of 37px), the top bar and the larger spacing steps, for data-heavy screens such as dashboards, admin tools and this documentation, which uses it.

Comfortable

Dense

More on screen.

  • ORCA["DENSITY"] = "dense" writes data-density="dense" on <html> through orca_html_attrs. One template can choose its own: {% templatetag openblock %} orca_html_attrs density="dense" {% templatetag closeblock %}.
  • data-density="dense" also works on a single region (a table panel, a sidebar) while the rest of the page stays comfortable.
  • Density never costs accessibility: body text stays at 14px or more, contrast is unchanged, and every control still grows to the 44px touch minimum on touch screens. For long reading, keep the comfortable density.
