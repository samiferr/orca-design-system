The working loop

  1. Find the element for the job on the primitives pages, or with python -m orca search <words>.
  2. Read its when not to use first: it usually names the element you need instead.
  3. Copy the example template, then replace the content. Keep the classes, attributes and structure.
  4. Run python manage.py orca_lint before you commit.

Filters

  • {% templatetag openvariable %} minutes|orca_duration {% templatetag closevariable %}: 90 becomes “1 h 30 min”. Accepts an integer of minutes or a timedelta.
  • {% templatetag openvariable %} user.get_full_name|orca_initials {% templatetag closevariable %}: “Ada Lovelace” becomes “AL”.

Layout helpers

Primitives do not set outer margins. Space groups with the spacing tokens and the two utilities .orca-stack (a column with an 8px gap) and .orca-row (a wrapping row; .orca-row--16 for 16px). For anything else use gap: var(--orca-space-24) and friends in your own CSS.

Your own CSS

ORCA's rules live in cascade layers (orca.tokens, orca.base, orca.primitives, orca.utilities), so any unlayered rule of yours wins without !important. Use that for layout only. Read every colour, size, radius, shadow, layer and duration from a --orca-* token, and never redefine a token other than the brand ones.
