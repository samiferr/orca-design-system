Add ORCA to your agent instructions

Markdown
# UI rules (CLAUDE.md, AGENTS.md or your agent's equivalent)
This project's interface uses the ORCA design system.
- Before writing any UI, run `python -m orca search ` and `python -m orca show `.
- Copy the element's example and keep its classes and attributes; change only the content.
- Use --orca-* tokens for every colour, size, radius, shadow, layer and duration.
- Change brand values only in settings.ORCA["BRAND"].
- Run `python manage.py orca_lint templates/` and fix every finding before you finish.

The hard rules

  1. Tokens only. Never hard-code a colour, size, radius, shadow, z-index or duration.
  2. Brand tokens only can change, and only in settings.
  3. Only classes that exist. Compose missing pieces from primitives with .orca-stack and .orca-row.
  4. One primary action per screen. A destructive first step is never red; confirm it with --danger in a dialog.
  5. Every control has a visible label. Help between label and field; errors above the field, with an icon and a fix.
  6. Status is never colour alone. A word plus an icon or shape.
  7. ORCA icons only; icon-only buttons need aria-label.
  8. Every button has a type; every image has alt.
  9. Native controls first: date inputs, select, dialog, details, progress.
  10. Page filters live in a right drawer, opened by a Filters button in the page actions; applied filters show as removable tags. See Drawer backdrop.
  11. Grounds as in wise_people_analyzer: --orca-bg-page behind, --orca-bg-panel for panels and the sidebar, --orca-bg-stat for stat cards, --orca-brand-bar for the top bar.
  12. Write like ORCA: sentence case, verbs on buttons, no exclamation marks, digits for numbers, errors that say how to fix.

What the lint catches

Shell
$ python manage.py orca_lint templates/
templates/images/list.html:12: hard-coded colour; use a --orca-* token.
templates/images/list.html:18: icon-only button without aria-label.
templates/images/list.html:22: unknown ORCA class 'orca-buton'. Run `python -m orca search` to find the right one.
static/css/site.css:4: --orca-text is not a brand token; only brand tokens may be changed (settings.ORCA['BRAND']).
4 problem(s) found.

It exits with status 1 when it finds a problem, so it can gate continuous integration as well as an agent's loop.
