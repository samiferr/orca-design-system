ORCA has five levels. Each level is a group of the level before it, and only of that level. Each release completes one level.

Each component, pattern and template lists what it is built from: elements of the level directly below, or of its own level when it nests one. A level is never skipped, and a part is listed once: when a listed element already contains it, it is not listed again. The test suite enforces both.
