Each component, pattern and template lists what it is built from: elements one level down, or from its own level when it nests one. No level is skipped, and a part already contained in a listed element is not listed again. The tests enforce both rules.

ORCA adds a few things the guide does not list: a skeleton loading primitive, realistic sample data in orca.samples, and template tags that render components from Django objects: orca_field, orca_form_errors, orca_messages, orca_pagination, orca_mini_calendar, orca_sparkline and orca_donut.

For patterns, there are Chart.js charts and server-rendered calendars: orca_chart, orca_month_calendar, orca_week_view, orca_agenda, orca_year_view. Emails get an inline-styled frame (orca/email/base.html).
