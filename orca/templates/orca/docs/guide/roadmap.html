The five levels

  1. Primitives {% icon "success" %}Released

    Atoms. The smallest working pieces and the base styles: buttons, inputs, icons, text styles, marks, tokens.

  2. Components {% icon "success" %}Released

    Molecules. Small groups with one job: form fields, search bar, date picker, pagination, stat card, toast, calendar parts.

  3. Patterns {% icon "success" %}Released

    Organisms. Recognisable sections: header, sidebar, data table, filter bar, charts, schedule editor, month calendar, kanban board.

  4. Templates {% icon "success" %}Released

    Django templates you extend: app shell, auth, error and email layouts, generic CRUD and parent-child templates, dashboard, calendar, scheduler, board and timeline pages, structural layouts and slots.

  5. Pages {% icon "info" %}Next

    Templates filled with real content, including the variations that test them: empty, overdue, right-to-left, dark.
