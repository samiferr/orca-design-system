What an element looks like

Each record in the catalogue answers the same questions, in the same order. Developers read it on these pages; agents read it with python -m orca show switch or from catalogue.json.

Why
The user need, tied to a named principle.
When, and when not
The situations it fits and the alternatives to use instead.
How
Exact markup, classes, sizes and wording rules.
Accessibility
What assistive technology needs from the markup.
Tokens and principles
The --orca-* values it reads and the rules it applies.
Example
A template snippet that renders on this site and in your project.

Start in three steps

  1. Install
    Shell
    pip install git+https://github.com/samiferr/orca-design-system.git
  2. Add the app and your brand
    Python
    INSTALLED_APPS += ["orca"]
ORCA = {"BRAND": {"name": "Acme", "color": "#0f95a1"}}
  3. Load it in your base template
    Django template
    {% verbatim %}{% load orca %}
<html {% orca_html_attrs %}>
<head>{% orca_head %}</head>{% endverbatim %}
