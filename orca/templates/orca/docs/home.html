Interfaces drift when nobody writes the rules down

Two developers build two list pages and end up with two kinds of buttons, three shades of grey and a delete action that is sometimes red and sometimes not. An AI coding agent makes the same mistake faster, because it has no rulebook to read: it guesses a class name, hard-codes a colour and moves on.

ORCA is the rulebook, kept next to the code. Every element lives in a catalogue that people read on this site and agents read from the command line, so a dashboard built on Monday and a dashboard built in March look like one product.

The Dashboard template with placeholder content. The charts come from one template tag each.

Primitives are the smallest pieces: buttons, inputs, badges, icons. Components group a few of them into one job, such as a field with its label and help text. Patterns are recurring sections: data tables, forms, charts, calendars, schedulers, planning boards. Templates are whole pages you extend.

Prefer the highest level that fits. A list page needs one template and your queryset, not forty primitives.

A records list from the Generic list template. One primary action, filters in a drawer, pagination and counts included.

Complex screens come from your data

Charts, calendars and boards are not drawn by hand. You pass plain data to a template tag and ORCA draws the result in token colours, so it follows your brand and your theme.

Django template
{% verbatim %}{% orca_chart "bar" data %}
{% orca_month_calendar events %}
{% orca_week_view events days=7 %}{% endverbatim %}

The Calendar page: toolbar, month view and side panel from a list of events.

The Scheduler page: resources by time.

One brand setting, three themes

Only brand tokens can change, and only in settings.ORCA["BRAND"]: {{ stats.brand_keys }} keys including name, logo, colour and fonts. Light, dark and paper themes ship with the system and every text and control colour is contrast-checked in all three.

The dashboard from the top of this page in the dark theme. Nothing was restyled: the tokens switched, and the charts redrew.

Made for agents as much as for people

Look up before you write. An agent searches the catalogue, prints the element it needs and copies the example, instead of inventing class names.

Shell
python -m orca search switch
python -m orca show switch
python manage.py orca_lint templates/

The last command checks your templates for hard-coded colours, unknown classes, buttons without a type and images without alt text. The guide for AI agents and the repository's AGENTS.md give the rules in full.

Start in three steps

  1. Install
    Shell
    pip install git+https://github.com/samiferr/orca-design-system.git
  2. Add the app and your brand
    Python
    INSTALLED_APPS += ["orca"]
ORCA = {"BRAND": {"name": "Acme", "color": "#0f95a1"}}
  3. Load it in your base template
    Django template
    {% verbatim %}{% load orca %}
<html {% orca_html_attrs %}>
<head>{% orca_head %}</head>{% endverbatim %}

Then extend a template: the installation guide covers the rest.
